# Four Forces Analysis — social-sharing

## JOB-006: Civic Advocacy

### Push (current frustration)
- Cannot share ideas from the platform — must manually copy the browser URL, switch to WhatsApp/Facebook, paste, and write context. This takes 30+ seconds and I usually don't bother.
- When I do share, the link shows no preview on WhatsApp/Facebook — just a bare URL that looks like spam. Recipients ignore it.

### Pull (desired future)
- One-tap share button on every idea detail page with pre-filled message: idea title, category, district, and a call-to-action ("Support this idea for our neighborhood").
- Rich OG preview renders automatically when the link is pasted — recipients see the idea image, title, and support count without clicking.

### Anxiety (adoption concerns)
- Will sharing feel spammy if the pre-filled text is too pushy?
- Will my Facebook/WhatsApp contacts judge me for "being political"?
- What if I share an idea that later gets rejected — does that reflect badly on me?

### Habit (current behavior that must change)
- Currently: copy URL → open WhatsApp → paste → type context manually → send. Usually skip sharing because it's too much effort.
- New: tap share button → choose channel → send with auto-generated context. 3 seconds instead of 30.

## JOB-007: Credible First Impression

### Push (current frustration)
- Shared ClujParticipa links show blank/generic previews in messaging apps and social feeds. Recipients have no idea what the link is about without clicking.

### Pull (desired future)
- Every idea link renders a rich preview card: title, first image (or category-colored placeholder), district, support count, and a "Support this idea" CTA in the OG description.

### Anxiety (adoption concerns)
- None significant — this is a passive improvement. Recipients don't "adopt" anything; the experience just improves.

### Habit (current behavior that must change)
- Currently: recipients see a bare URL and either ignore it or click with low confidence.
- New: recipients see a compelling preview card and click with intent. No behavior change required from the recipient — the platform generates the preview automatically.
