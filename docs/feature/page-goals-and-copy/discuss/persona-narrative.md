# Persona Narrative — page-goals-and-copy

## Ion — Curious Newcomer

**Archetype**: Skeptical Observer
**District**: Gheorgheni
**Tech comfort**: Low-moderate
**First language**: Hungarian

### Goals (per page)
- **Homepage**: "Is this real? Does anyone use it?" → needs social proof in 10 seconds
- **Ideas List**: "Are there ideas from my area?" → needs district filter to be obvious
- **Idea Detail**: "Has anything actually been completed?" → needs completed count or pipeline with filled stages
- **How It Works**: "Is there a real process or is this just another complaint box?" → needs to see stages lead to outcomes
- **Results**: "Proof that it works" → needs visible completed/selected ideas
- **Login**: "Why do they need my account?" → needs privacy-first framing before clicking
- **Submit**: "Will anyone even read this?" → needs reassurance that submission enters a pipeline

### Frustrations
- Government websites that collect input and disappear
- Platforms that look like startups, not civic institutions
- Having to read Romanian when Hungarian is preferred
- Being asked to "create an account" for something he's not sure is legitimate

### Mental model (per page context)
- Homepage: "This is like a local newspaper site — should feel serious and local"
- Idea Detail: "Like a petition tracker — I want to see where this stands"
- How It Works: "Like tracking a package — I want to see the journey"
- Login: "Like signing a petition — I need to know what I'm committing to"

### Vocabulary (their words vs. platform terms)
| Platform term | Ion's word |
|--------------|-----------|
| Idea | Suggestion |
| Status | Is anything happening |
| Vote | Support |
| Pipeline | Where it is in the process |
| Submit | Propose |
| Feasibility | What the city says |
| Non-binding | Prototype / demo |

### Copy implications
- Headlines should use "propose" not "submit" where possible (warmer, less bureaucratic)
- Status labels should answer "is anything happening" — not just name the state
- Hungarian translations should feel native, not like Romanian translated word-by-word
- Every page Ion visits must show completed/active count — he needs proof at every step

## Maria — Engaged Resident

**Archetype**: Package Tracker
**District**: Manastur
**Tech comfort**: Moderate
**First language**: Romanian

### Goals (per page)
- **Homepage**: "Is my idea still moving? Are others participating?" → needs activity signals
- **Ideas List**: "Find ideas I want to support" → needs efficient filtering
- **Idea Detail**: "What's happening with this idea? Should I support it?" → needs pipeline + feasibility + comments
- **Submit**: "I have a specific problem — let me report it fast" → needs minimal friction
- **How It Works**: "I already know the process — show me it works" → needs completed proof, not process explanation
- **Results**: "Did my support matter?" → needs to see selected ideas she supported
- **Login**: "I just want my vote to count across devices" → needs benefit framing, not explanation

### Frustrations
- Posted on Facebook last year — nothing happened
- City hall website has no feedback mechanism
- Doesn't want to create another account
- Gets anxious when pipeline stages don't move
- Feels like she wasted her time when she sees stalled ideas

### Mental model (per page context)
- Homepage: "Like checking a community board — is anything new?"
- Idea Detail: "Like a package tracker — where is it? when will it move?"
- Submit: "Like filling in a form at the town hall — but hopefully faster"
- Pipeline: "The stages are like delivery milestones — I check back to see progress"

### Vocabulary (their words vs. platform terms)
| Platform term | Maria's word |
|--------------|-----------|
| Idea | Proposal |
| Status | What's happening with it |
| Pipeline | Where it is in the process |
| Support | Backing |
| Status change | Update |
| Stalled | Stuck / forgotten |
| Non-binding | Prototype / demo |

### Copy implications
- Success message after submission is the #1 emotional moment — "Your idea is now in the pipeline" is essential
- Stalled indicator language matters: "Waiting for" is good; "Stuck" would be alarming
- Section headings on detail page should match her mental model ("How this idea has progressed" not "Status History")
- Pipeline stage names should feel like milestones, not bureaucratic statuses

## Operator — Platform Steward

**Archetype**: Data-Driven Steward
**District**: N/A (internal)
**Tech comfort**: High

### Goals (per page)
- **Admin**: "Manage the platform efficiently" → functional copy, no editorial ambitions
- **Homepage (as observer)**: "Are the copy changes moving the metrics?" → needs KPI instrumentation
- **All pages (as operator)**: "Are users dropping off somewhere? Why?" → analytics signals

### Frustrations
- No analytics — every UX decision is a guess
- Cannot tell if editorial redesign improved engagement
- Cannot show coalition partners evidence of platform health

### Copy implications
- Admin page copy is functional and adequate — no changes needed
- KPI tracking (Umami events) on copy-affected pages is a measurement dependency
- Operator cares about whether copy changes move metrics, not the specific words
