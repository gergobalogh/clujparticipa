## Priority Focus

**Top 3 opportunities** (copy changes will have the highest impact here):

1. **J-HOME (54)** — The homepage is the #1 trust-and-action bottleneck. Copy must answer "what is this?" and "what do I do?" in under 10 seconds.
2. **J-SUBMIT (45)** — Submission anxiety is the #2 drop-off. Form copy must transform the experience from bureaucracy to civic action.
3. **J-RESULTS (28)** — Results are the trust proof but the current page doesn't tell the impact story. Copy must make outcomes visible and shareable.

**Moderate opportunities** (refinement, not overhaul):

4. **J-DETAIL (24)** — Detail page has good structure but needs micro-copy at each scroll depth to guide the user's decision journey.
5. **J-HOW (21)** — Process page works but reads like docs, not motivation. Light reframing needed.
6. **J-AUTH (14)** — Auth page is functional but the copy framing could reduce login anxiety.
7. **J-PRIVACY (12)** — Privacy page is adequate but dense. Scannability improvement needed.

**Low/no action needed:**

8-13. Ideas list, Map, Admin, Bug report, Terms, Data deletion — all appropriately or over-served. No copy overhaul needed; maintain current quality.
