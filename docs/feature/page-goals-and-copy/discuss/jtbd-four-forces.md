# Four Forces Analysis — page-goals-and-copy

## J-HOME: Homepage Scanner

| Force | Description |
|-------|-------------|
| **Push** | Current homepage lacks a clear value proposition — visitor can't tell in 10 seconds what this is, whether it's alive, or what to do |
| **Pull** | Editorial layout with map, live stats, recent idea feed, and a single clear CTA makes the purpose and activity obvious at a glance |
| **Anxiety** | "Is this a real city platform or just someone's side project?" — low institutional trust in Romanian civic tech |
| **Habit** | Visitors default to scanning and leaving; they don't read paragraphs of explanation. The page must SHOW, not TELL. |

## J-DETAIL: Idea Deep-Diver

| Force | Description |
|-------|-------------|
| **Push** | Detail page shows raw data but lacks narrative — pipeline is visual but the "why should I care?" framing is missing |
| **Pull** | Each section of the detail page has a clear micro-goal (understand status → decide to support → read community reaction → share) |
| **Anxiety** | "Is my vote actually counted? Is this binding?" — the non-binding label exists but is easy to miss |
| **Habit** | Users scan titles and status badges, rarely read full descriptions. Copy must earn attention at each scroll depth. |

## J-SUBMIT: Idea Proposer

| Force | Description |
|-------|-------------|
| **Push** | Form exists but feels bureaucratic — no emotional framing about why this matters |
| **Pull** | Form copy that frames submission as "Your neighborhood needs your voice" transforms the same fields from bureaucracy to civic action |
| **Anxiety** | "Will anyone read this? Is there a point?" — submission anxiety is the #1 drop-off risk |
| **Habit** | People complain on Facebook. The form competes with the habit of low-effort venting. Copy must make this feel more impactful. |

## J-HOW: Process Learner

| Force | Description |
|-------|-------------|
| **Push** | Process page exists but reads like documentation — informative, not motivational |
| **Pull** | Same pipeline visualization reframed as "Your idea's journey from submission to implementation" makes the process feel personal |
| **Anxiety** | "Does anything actually get implemented?" — the completed count is the antidote but it's buried |
| **Habit** | Skip it. Most users never click "How It Works" unless they're already engaged. Copy must earn the click from the homepage. |

## J-RESULTS: Outcome Verifier

| Force | Description |
|-------|-------------|
| **Push** | Results page is sparse — it shows data but doesn't tell the story of community impact |
| **Pull** | "Here's what your community chose" framing transforms a data table into a trust-building moment |
| **Anxiety** | "Was voting fair? Are these real results?" — transparency is the trust engine |
| **Habit** | Results pages are visited once and forgotten. Copy must make it shareable. |

## J-AUTH: Identity Connector

| Force | Description |
|-------|-------------|
| **Push** | Auth wall interrupts the participation flow — feels like a barrier, not an enabler |
| **Pull** | "One click to make your support count across devices" reframes login as empowerment |
| **Anxiety** | "Why does a civic platform need my Google account? What data do they take?" |
| **Habit** | People avoid new logins. Framing must make OAuth feel lighter than the alternative (creating yet another account). |

## J-PRIVACY: Trust Builder

| Force | Description |
|-------|-------------|
| **Push** | Privacy page exists but is legal-first, not human-first — walls of text |
| **Pull** | Clear, jargon-free privacy notice that a neighbor could understand |
| **Anxiety** | "Is my data being sold? Am I being tracked?" — GDPR awareness is high in Romania |
| **Habit** | Nobody reads privacy pages unless they're already suspicious. Copy must be scannable. |
