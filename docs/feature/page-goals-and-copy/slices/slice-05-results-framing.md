# Slice 05 — Results Page Impact Framing

**Goal**: Frame voting results as community achievement, not a data table

**IN scope**:
- Add framing sentence when selected ideas exist (using `Results.*` namespace)
- Rewrite `Results.selectedHeading` to be community-oriented
- Update `Results.noResults` empty state with CTA

**OUT scope**:
- Voting period display (already exists)
- New components
- Selected/winner badge changes

**Learning hypothesis**: Disproves "results framing doesn't affect engagement" — if click-through rate on selected ideas is unchanged, community framing doesn't drive deeper engagement.

**ACs**:
- Framing sentence appears when selected ideas exist
- Heading is community-oriented
- Empty state includes CTA link
- All strings in RO, HU, EN

**Dependencies**: None

**Effort estimate**: ≤4 hours
