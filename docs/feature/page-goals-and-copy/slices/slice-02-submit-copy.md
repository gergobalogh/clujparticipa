# Slice 02 — Submit Page Emotional Framing

**Goal**: Transform the submission form from bureaucracy to civic action with emotional framing and next-step reassurance

**IN scope**:
- Rewrite `NewIdea.title` and `NewIdea.description` to be encouraging and action-first
- Rewrite `NewIdea.locationHint` to be personal
- Rewrite `NewIdea.success` to include pipeline/next-step reassurance
- Add link to How It Works from success state

**OUT scope**:
- Form field changes (preserve existing fields)
- Validation logic
- New components

**Learning hypothesis**: Disproves "submission anxiety is not a copy problem" — if form completion rate is unchanged after 2 weeks, the barrier is structural, not emotional.

**ACs**:
- `NewIdea.title` is action-first and encouraging
- `NewIdea.description` frames the form as civic action
- `NewIdea.locationHint` is personal ("Pin the spot...")
- `NewIdea.success` includes pipeline reference
- All strings in RO, HU, EN

**Dependencies**: None

**Effort estimate**: ≤4 hours
