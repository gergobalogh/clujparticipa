# Slice 01 — Homepage Copy Reframe

**Goal**: Make the homepage answer "what is this?" and "is it alive?" within 10 seconds

**IN scope**:
- Rewrite `Home.description` to ≤20 words, action-first
- Localize `Home.eyebrow` to RO-appropriate term ("Bugetare Participativă")
- Update empty state copy to be actionable
- Verify stats strip shows completed count

**OUT scope**:
- Layout changes (preserve split sidebar + map)
- LIVE badge changes (preserve existing)
- New components
- Ideas list page copy

**Learning hypothesis**: Disproves "homepage copy has no effect on bounce rate" — if bounce rate is unchanged after 2 weeks of Umami data, copy alone doesn't move the needle on this page.

**ACs**:
- `Home.description` ≤20 words
- `Home.eyebrow` is "Bugetare Participativă" in RO
- Empty state copy includes a CTA
- All strings in RO, HU, EN

**Dependencies**: None

**Effort estimate**: ≤4 hours (locale file edits + visual verification)
