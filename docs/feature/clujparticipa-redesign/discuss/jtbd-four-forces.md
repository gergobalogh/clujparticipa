# Four Forces Analysis — clujparticipa-redesign

## JOB-001: "Submit my idea and track whether it gets acted on"

### Push (current frustration)

- Residents submit ideas to Facebook groups, city hotlines, or in-person meetings and never hear back
- No way to know if an idea was received, reviewed, or rejected — or why
- When status changes happen (if ever), they're invisible — residents must actively chase for updates
- The current prototype shows status as a badge ("SUBMITTED", "UNDER_REVIEW") with no timeline, no attribution, and no context — the badge is a dead end, not a starting point

### Pull (desired future)

- See a visual pipeline showing exactly where an idea stands and what comes next
- Know who is responsible at each stage (reviewer, department, admin)
- Get notified when an idea moves to a new stage
- See estimated timelines or explicit "waiting for [X]" labels
- Understand why an idea was returned, stalled, or rejected — not just that it was

### Anxiety (adoption concerns)

- "If I can see the pipeline but nothing moves, I'll feel worse than not seeing it at all"
- "What if my idea is 'Under Review' for 6 months — will the pipeline just make the silence louder?"
- "I don't want to create an account just to track an idea — too much friction"
- "Will my personal data be safe? Can the city see who I am?"

### Habit (current behavior must change)

- Current habit: submit and forget (or submit and post on Facebook to complain that nothing happened)
- Current habit: check the idea detail page occasionally, see the same status badge, give up
- Current habit: treat the platform as a one-way suggestion box, not a tracking tool
- **Behavior change required**: from "submit and hope" to "submit and follow" — the pipeline must make checking back feel rewarding, not punishing
